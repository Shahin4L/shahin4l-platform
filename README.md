# SHAHIN4L — New Platform

A fresh Next.js foundation for Md Shahin Alam's professional personal brand.

## Important boundary
This is a new project. It does not modify or replace the existing `shahin4l.github.io` repository or its live website.

## Stack
- Next.js App Router
- React + TypeScript
- Tailwind CSS v4
- Lucide icons
- Vercel-ready deployment configuration

## Local development

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Build check

```bash
npm run build
```

## Deploy to Vercel
1. Create a new GitHub repository named `shahin4l-platform`.
2. Push this project to that repository.
3. Import the new repository in Vercel.
4. Keep the framework preset as Next.js and deploy.

The suggested Vercel project name is `shahin4l-platform`; the final `*.vercel.app` address depends on availability.
